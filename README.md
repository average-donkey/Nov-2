# Palakus Maximus — Black Space Edition

A phone-first dark-space version with a black gradient, denser animated stars, CSS-drawn planets, a black hole, subtle green/teal aurora, and more transparent glass typography.

## Run it
Keep `index.html`, `style.css`, and `script.js` together and open `index.html`, or upload all three files together to your host.

The planets, black hole, and aurora are lightweight CSS decorations rather than large image assets. The existing countdown, custom text, constellation notes, secrets, and moon Easter egg remain in `script.js`.

JavaScript syntax checked with `node --check`; the page has not been tested on every device/browser.
